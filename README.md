# pdt-hints

Metadata for the [Health Information National Trends Survey (HINTS)](https://hints.cancer.gov/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

The National Cancer Institute's nationally representative survey of US adults about access to and use of health and cancer information, cancer risk perceptions and health behaviors, fielded in cycles since 2003.

## Terms of use

The terms are at https://hints.cancer.gov/data/download-data.aspx. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

National Cancer Institute. Health Information National Trends Survey (HINTS).

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
