# pdt-hints

Metadata for the [Health Information National Trends Survey (HINTS)](https://hints.cancer.gov/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** 1,380 variable records for three cycles, HINTS 5 Cycle 4 (2020), HINTS 6 (2022) and HINTS 7 (2024), every variable in each public-use file, built from NCI's codebooks and checked against the Stata files. The terms are decided (everything ships), but nothing is published yet.

## What the dataset is

The National Cancer Institute's nationally representative survey of US adults about access to and use of health and cancer information, cancer risk perceptions and health behaviors, fielded in cycles since 2003.

## Terms of use

The terms are at https://hints.cancer.gov/data/download-data.aspx. Downloads need no login or registration. NCI asks users not to publish anything that could identify a respondent, including small cells, not to link the data to identified records, and not to try to learn anyone's identity; NCI text is free of copyright, with credit to NCI. Allen Downey reviewed the terms on 2026-11-20: the metadata, the documentation and the common-format data ship, with this notice:

> Source: National Cancer Institute, Health Information National Trends Survey (HINTS), public-use data. Users must not publish anything that could identify a respondent, including small cells, must not link the data to identified records, and must not attempt to identify anyone.

What the sources say is quoted in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: one zip per cycle from the [download page](https://hints.cancer.gov/data/download-data.aspx), holding the Stata file and the documentation. `make download ARGS=--accept-terms` fetches them. The build reads each codebook as text: unzip the zips into `data/interim/` and run `pdftotext -layout` on each `* Public Codebook.pdf`.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from. Releases are `hints5-cycle4`, `hints6` and `hints7`; each record's `source_location.page` is its page in that cycle's codebook PDF.
- Missing codes are HINTS's negative codes, typed by rule `hints_missing_types`: -1 inapplicable and -2 answered in error are `inap`; -9 not ascertained is `skipped` (HINTS is self-administered); -7 web partial, never seen, is `not_asked`; -6 filter missing is `inap` or `skipped`; -4 and -5 are `uncodeable`.
- `metadata/links.jsonl`: 226 `same_item` links between consecutive cycles, by rule `hints_same_name_identical`: the same name, question text, universe and valid codes in both cycles (NCI's merge code matches variables by name). Items with the same name that changed in any way aren't linked, because HINTS's documentation doesn't say what changed; `build/links_report.md` lists them.
- Weights: `PERSON_FINWT0`, with 50 jackknife (JK1) replicate weights `PERSON_FINWT1`–`PERSON_FINWT50`; `VAR_STRATUM` and `VAR_CLUSTER` for Taylor series (`dataset.yaml`, `design`).
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```

The metadata tools (`make views`, `make check`) need only the toolkit's base install
(`pip install -e ../PublicDataToolkit`). Building or reading the data files (`make data`,
`scripts/extract.py`, and the data checks in `make check`) also needs pandas, numpy and
pyarrow: `pip install -e "../PublicDataToolkit[data]"`. Without them, `make check` skips
the data checks and says why.
